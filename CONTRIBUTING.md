# 🤝 Как работаем с репозиторием

1. **Одна ветка — одна тема:** `internal/motivation`, `research/competitors` и т.п.
2. **Pull request** в `main` с кратким описанием; ревью хотя бы одного участника команды.
3. **Задачи** заводим через Issues по шаблону «Идея» — [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE/).
4. **Стиль документов:** таблицы и схемы Mermaid вместо длинных абзацев; каждый документ начинается с вопроса кейса, на который отвечает.
5. **Факты** о компании и конкурентах — только со ссылкой на источник.

## Коммиты
```
docs(internal): добавить трек для АЗС
docs(metrics): уточнить пороги
research: добавить компанию в анализ
```
